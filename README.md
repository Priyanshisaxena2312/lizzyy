# 🦎 Lizzy — A Gecko Habitat

An interactive gecko habitat experience where you can explore a virtual terrarium, interact with Lizzy, and monitor her environment.

## ✨ Features

- 🦎 **Interactive Gecko:** Lizzy follows your cursor around the screen.
- 🪲 **Feed Lizzy:** Click anywhere to drop a bug and interact with her.
- 🌡️ **Temperature Monitoring:** Displays the terrarium temperature.
- 💧 **Humidity Monitoring:** Shows the habitat's humidity level.
- 📊 **Sensor Dashboard:** Tracks environmental conditions and bugs eaten.
- 🎨 **Interactive Experience:** A playful and engaging virtual terrarium.
